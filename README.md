# やまぐちジュニアプログラミングコンテスト 発表タイマー（同期対応）

最終審査会場の発表タイマー。**司会・運営が1台で操作すると、同じURLを開いている全員の画面が同じカウントダウンになります。**

- 発表 2:00 → 延長（最大 +1:00）→ 質疑応答 2:00 の3ステージ
- 残り30秒で予鈴、2:00で鐘2回、3:00で鐘3回 → 自動で質疑応答へ
- 黒地＋JPC カラー。数字は画面いっぱい、状態は色で判別（白→黄→橙→ピンク点滅）

## 観覧用QRコード（ホスト画面に表示）

ホスト画面の右上「観覧用QR」を押すと、**観覧用URLのQRコードが画面に出ます**。会場で読み取ってもらうだけで、その端末が同じカウントダウンに参加します。

- `Q` キーでも開けます
- 「URLをコピー」でチャットや配布資料にも貼れます
- `?qr=1` を付けて開くと最初からQRが出た状態になります（受付・キオスク用）
- QRはブラウザ内で生成しています（外部サービス・外部ライブラリ不要、オフラインでも表示可）

QRの中身は、いま開いているホストのURLから自動で作られます。

```
http(s)://<ホスト>/...?view=1&room=main
```

`room` は会場やセッションを分けるときに使います（例: `?room=b` で開いたホストのQRは `room=b` の観覧用になります）。

## 2つの使い方

### 1) 同期モード（推奨・複数端末で同じカウントダウン）

```bash
node server.js          # Node.js 18 以上。依存パッケージなし
```

起動するとURLが表示されます。

| 用途 | URL | 画面 |
|---|---|---|
| 操作（ホスト／司会のタブレット） | `http://<ホスト>:8080/` | 操作ボタンあり |
| 観覧（会場スクリーン・審査員・保護者） | `http://<ホスト>:8080/?view=1` | ボタンなし・数字が大きい |
| 別会場・別セッションに分ける | `...?room=b` のように `room` を付ける | ルームごとに独立 |

- ホストが「開始」を押した瞬間、観覧側も同じ位置から減り始めます（途中から開いても残り時間は正しい）
- 一時停止・次へ・リセット・発表者名・設定変更もすべて同期
- 人数制限なし。観覧側は自動再接続（回線が切れても復帰します）
- 端末の時計が数秒ずれていても、サーバー時刻に合わせて補正します（60秒ごとに再補正）

**同じWi-Fi内なら会場LANだけで完結**します（インターネット不要）。司会のノートPCで `node server.js` を起動し、表示された `http://192.168.x.x:8080/?view=1` をスクリーンや各端末で開くだけです。

### 2) 単体モード（1台だけ）

`index.html` を直接開く／GitHub Pages に置く。従来どおり、その端末だけで動きます（右上に「単体モード」と表示）。

> **GitHub Pages は静的ホスティングなので同期はできません。** 同期させたい場合は `server.js` を動かせる場所（会場PC／Render／Railway／VPS など）に置いてください。`?view=1` を付けた観覧ページだけを公開する、という使い方もできます。

## インターネット越しに配信する場合

- **Render / Railway** … リポジトリを接続し、Start Command に `node server.js`。ポートは `PORT` 環境変数に対応済み
- **Cloudflare Tunnel** … 会場PCで `node server.js` → `cloudflared tunnel --url http://localhost:8080` で一時URLを発行
- **VPS** … `node server.js` を systemd などで常駐

## 当日の進行

1. ホスト端末で `node server.js` を起動（または公開URLを開く）
2. ホスト画面で発表者名を入力
3. 観覧用 `?view=1` をスクリーン／各端末で開く（最初に一度タップすると音が有効になります）
4. 「開始」→ 2:00 カウントダウン → 0:30 予鈴 → 2:00 鐘2回 → 延長（橙の+カウント）→ 3:00 鐘3回 → 自動で質疑応答
5. 終了したら「リセット」で次の発表者へ

### キーボード（ホスト）

| キー | 動作 |
|---|---|
| `Space` / `Enter` | 開始・一時停止 |
| `→` | 次のステージへ |
| `R` / `Esc` | リセット |
| `F` | 全画面 |
| `M` | 消音 |

## 設定（右上「設定」・端末に保存）

発表時間（120秒）／限界までの延長（60秒）／質疑応答（120秒）／終了30秒前の予鈴 ON/OFF／音量。

## 仕組み

- 状態は「ステージ・開始/停止・終了予定時刻（絶対epoch）・設定・発表者名」だけをサーバーで保持
- 配信は **Server-Sent Events**（`/api/events`）。ホストの操作は `POST /api/state` で1回送るだけ
- 各端末は「終了予定時刻 − 現在時刻」で数字を出すので、**何秒遅れで参加してもズレません**
- サーバーは状態をメモリに持つだけ（DB不要）。再起動すると初期状態に戻ります
- QRコードは `qr.js`（最小構成のQRエンコーダ・依存なし）でブラウザ内生成。`index.html` にはインラインで埋め込んであります

## 音について

ベルは Web Audio API の合成音（音声ファイルなし）。ブラウザの仕様で**最初のタップ後**に有効になります。観覧モードでは「画面をタップして音を有効にする」を一度押してください。

## 端末メモ

- **iPad / iPhone**: スリープ抑止（Wake Lock）非対応。設定 → 画面表示と明るさ → 自動ロック → 「なし」
- **Android / Chrome**: スリープ抑止対応。全画面表示と併用
- 音が出ないときはマナーモードと音量を確認
